# AetherRendering v2 — AI Director → HyperFrames → Kokoro → MP4

This is an **additive** system. It does not change `src/render.py`, the previous GitHub Actions workflow, or the existing validated FFmpeg demo files.

## Choose the workflow

1. Open [AetherRendering Actions](https://github.com/SaridakisStamatisChristos/AetherRendering/actions).
2. Select **AI Video — HyperFrames + Kokoro** and **Run workflow**.
3. Set `topic` and choose `provider`:
   - `demo`: uses a deterministic sample narration and creates genuine animated HTML composition source; **not** AI-generated content.
   - `gemini`: calls the Gemini API to write original scene titles, subtitles, narration and motion instructions. Requires `GEMINI_API_KEY` saved as a repository **Actions secret**; no secret is ever committed. Choose a model available to your account.
4. Leave **render_video** checked to generate Kokoro narration, render both MP4s with HyperFrames and decode-test exports. The first run downloads rendering/TTS models and a browser, which may take considerable time and GitHub Actions minutes.
5. Download the `AetherRendering-AI-*` artifact from that workflow run. The output is kept by GitHub for up to 90 days; preserve releases separately if needed.

**Status:** The Python scene director, safe HTML compiler and their unit tests were verified locally. The new GitHub Actions workflow, live Gemini calls, Kokoro model inference and HyperFrames MP4 output require a successful workflow run before they may be called tested. The older FFmpeg demo is independently verified but does **not** prove this new pipeline.

## How code generation works

The AI Director **does not write arbitrary executable JS**. Its output is a constrained and checked JSON storyboard. `src/hyperframes_pipeline.py` compiles that data into actual HTML/CSS and deterministically seekable GSAP JavaScript animation code. This is deliberate: untrusted model-generated scripts should not run with arbitrary permissions on GitHub CI. Five motion presets are supported (`rise`, `slide`, `zoom`, `rotate`, `pop`); expand the compiler to add more motion effects and visual primitives.

The built-in Kokoro CLI synthesizes a WAV per scene. The pipeline measures each WAV's actual duration, adjusts the scene timeline, inserts each audio segment as a timed clip and then renders two separate aspect ratios. The audio is not generated by Gemini. No API key is required for local Kokoro after initial model setup.

## Local Ubuntu commands

```bash
# Prerequisites: Node.js 22+, Python 3.11+, git, ffmpeg, espeak-ng
sudo apt update && sudo apt install -y git ffmpeg espeak-ng python3-venv libsndfile1
# Install Node.js 22+ separately from an official Node.js distribution if system Node is older.
git clone https://github.com/SaridakisStamatisChristos/AetherRendering.git
cd AetherRendering
python3 -m venv .venv && source .venv/bin/activate
python -m pip install kokoro-onnx soundfile
python -m unittest discover -s tests -v
npx --yes hyperframes browser ensure
python src/ai_director.py --topic "How computers render animations" --provider demo --duration 25
python src/hyperframes_pipeline.py --tts --render --output build/exports
```

For an AI-written video, configure an API key **locally** (`export GEMINI_API_KEY=...`, never commit it), then:

```bash
python src/ai_director.py --topic "How computers render animations" --provider gemini --model gemini-2.5-flash --duration 30
python src/hyperframes_pipeline.py --tts --render --output build/exports
```

For fast, entirely offline compilation tests (no TTS, MP4, or API calls):

```bash
python src/ai_director.py --topic "Motion graphics" --provider demo --duration 25
python src/hyperframes_pipeline.py
# Open: build/hyperframes/vertical/index.html (via HyperFrames preview)
cd build/hyperframes/vertical && npx --yes hyperframes preview
```

## Notes and limitations

- Rendering is **not** fully local if you choose `provider=gemini`, because this invokes a cloud LLM. Kokoro narration and HyperFrames rendering are local on their host.
- The visual compiler currently supports animated typography and abstract motion graphic ornamentation. It **does not** autonomously generate images, footage, 3D models, or music; these require later adapters and licensing checks.
- TTS duration wins over estimated script timing; a requested length is a target, not an exact guarantee.
- Video output from this workflow is verified by `ffprobe` for H.264 size and `ffmpeg` for full decode. Studio visual review is still necessary. `hyperframes lint` runs before render; `hyperframes check` remains a recommended additional quality gate.
- Video templates use system fonts and no external copyrighted assets.
- Speech languages depend on Kokoro's voice catalog; Greek requires a different narrator backend.
- Keep secrets out of generated script, logs, HTML, and Git commits. The workflow intentionally requests read-only repository permission and does not publish binaries back to Git history.
