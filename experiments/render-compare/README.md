# AetherRendering vs Remotion — native HyperFrames engine comparison

This isolated experiment tests **AetherRendering's actual pinned HyperFrames 0.9.37 and GSAP 3.14.2** render stack, without installing Remotion. It leaves the production AetherRendering pipeline and `main` untouched.

## Matched content and output

- 10-second, 240-frame cinematic robot story, identical procedural SVG geometry and per-frame motion formulas to the first Remotion test.
- 1280 × 720, 24 fps, H.264 + AAC MP4.
- Same deterministic original 24 kHz mono WAV as the Remotion test (generated byte-identically by the exact same Python program).
- Distant and near-field parallax, walking robot, discovered glowing light, text entrance and end caption.
- Both engines run on separate Ubuntu-latest GitHub Actions jobs. Results are illustrative, **not** a controlled same-host benchmark.

This uses a purpose-built, seekable GSAP composition instead of the usual AI Director and Kokoro narrative compiler, to hold content constant and avoid including different narration-synthesis times. Thus it measures each **rendering engine**, not end-to-end AI generation. A follow-up production test should exercise AI Director, asset compilation, Kokoro narration and both output formats.

## Running locally (Ubuntu, Node 22+, Python 3.11+, FFmpeg)

From repository root:

```bash
npm ci
node_modules/.bin/hyperframes browser ensure
python3 experiments/render-compare/scripts/make_audio.py
python3 experiments/render-compare/scripts/build_scene.py
cd build/compare-aether/composition
"$OLDPWD/node_modules/.bin/hyperframes" lint
"$OLDPWD/node_modules/.bin/hyperframes" render --output "$OLDPWD/build/compare-aether/exports/aether.mp4" --fps 24
```

Run via `.github/workflows/aether-rendering-comparison.yml` on branch `experiment/aether-rendering-compare-v1` for full validation and `metrics.json` / `comparison.json` artifacts. A ratio below one for `aether_to_remotion_render_time_ratio` favors AetherRendering for this isolated render; a ratio above one favors Remotion. Different GitHub runners or encoder settings can bias comparisons.
